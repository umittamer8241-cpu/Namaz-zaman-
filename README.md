# Namaz Zamanı

Android 7.0+ telefonlar için günlük namaz vakitleri ve kıble uygulaması.
Çalışırken internet ve Google Haritalar açılması gerekmez.

- GNSS/GPS koordinatı otomatik alınır.
- Bugünün Sabah, Güneş, Öğle, İkindi, Akşam ve Yatsı saatleri hesaplanır.
- Sıradaki namaza geri sayım ve Kâbe yönü gösterilir.
- Telefon pusulası mevcutsa kıble oku telefonla birlikte döner.
- İnternet izni istenmez.

## APK

GitHub Actions > Namaz Zamanı APK Derle > son başarılı işlem > Artifacts > Namaz-Zamani-APK yolundan APK indirilir.
İki telefona da aynı APK kurulabilir.

## Dikkat
Saatler astronomik yaklaşımdır; resmî kurum vakitlerinden farklılık gösterebilir.
Saat dilimi ve telefon saatini doğru tutmak gerekir.
Gemide manyetik cihazlar ve çelik yapı pusulayı şaşırtabilir.
